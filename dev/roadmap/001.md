Description
--------------------------

Currently the Frame class is a subclass of pandas.DataFrame. The goal is to have an non-subclass Frame class that uses polars.DataFrame as the underlying data structure. This will allow for better performance and more flexibility in the future. The new class should be converted to polars or pandas df if needed. The new class should also be able to handle units and conversions, as Var and Array do. A big difference with Var and Array is that Frame is not a dataclass, and therefore is not frozen.
